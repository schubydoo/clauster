Using Clauster

Clauster spawns and manages remote-control bridges for your coding agent on this host, driven from the browser. Below is the short tour — the README has the full reference.

Launch modes

"Run Claude here" offers a few ways to start a session.

  • In claude.ai / Desktop — a remote-control bridge you drive from the Claude app on your phone or desktop. Under Advanced you can pick the resume behavior: Server Mode (multi-session; resume reconnects but doesn't replay the prior conversation) or Interactive Session (single session, true --continue resume — a service restart ends a live Interactive Session).
  • Here in the browser — a Direct Session: when enabled, watch the session work live and approve tools inline in this tab (not attachable from the apps).
  • Background Agent — runs unattended; check back later. It appears as a row in Active sessions with a background badge.

Permission modes

A session runs under a permission mode that decides how tool calls are approved — from prompting on every action to running unattended. Clauster fails closed: when a session needs a decision it can't make, it parks and waits for you rather than guessing.

The dashboard zones

  • Active sessions — what's running for you right now. Use the Stop / Resume controls on each row.
  • Projects — every discovered project. Launch a new session, create or clone a project, and open a project's read-only transcript here.

Managed vs. External sessions

The session filter sorts rows by who started the session. External (unmanaged) sessions are ones Clauster did not launch — for example a session started directly from the desktop or mobile app. Clauster can show them, but it has no lifecycle handle on them, so they carry no Stop or Resume control.

Tools in the header

  • Configuration editor (pencil icon) — edit operational settings; changes apply after a restart.
  • Theme toggle — switch between dark and light.
  • Log out — end your dashboard session (when auth is enabled).
